Permissions

This application uses the following Android permissions. Please grant all the required permissions by taping them above.

GPS Fine Location

The point of this application is to track the location of the device and record its path along a railroad. It uses the GPS to do so. GPS is needed when recording a new track as well as when playing an existing track.

Notification

To record and play a GPS track, the application needs to run in a loop, even if not visible. In this case, a notification is shown allowing you to easily switch back to the application. Modern Android OS versions require the application to do so. As such, the application must be authorized by the user to show its notification.
