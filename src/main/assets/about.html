Milepost Docent is an Android application that automates docent announcements for a heritage railway such as living history museums operating historic steam and diesel trains.

A GPS track is captured that corresponds to a train's scheduled route, and milepost numbers are associated with points along the track. The app automatically computes the train's current milepost based on its location relative to the expected track.

Pre-recorded docent audio segments are then programmed to play automatically at specific mileposts and travel directions as the train progresses on its journey.

Usage

1. Adding Audio Segments

Pre-recorded docent audio segments should be stored on the device. There are many apps on Android that let you record audio files, or you can record them separately using audio equipment and transfer them to the Android device via USB file transfer or online cloud services.

Once the files are copied on the Android device, they need to be registered with the Milepost application:

  • Navigate to Audio Segments from the navigation menu.
  • Tap the + button (or select Add File from the 3-dot menu) to pick audio files stored on your device using Android's system document picker.
  • The app requests persistent read permissions, checks the audio format and duration, and registers the file reference.
  • Use the list controls to preview audio playback or remove file references.
  • Red indicators highlight stale or missing file references -- this happens if the audio files are moved, renamed, or deleted.

2. Recording a GPS Track

At least one GPS track should be captured that corresponds to the train's scheduled route. When a train operates as a "back-and-forth shuttle", that is going from station A to station B and then reversing on the same route, you should only capture one of the directions on the route -- later, when programming docent annoucements, you'll be able to tailor them to the desired direction.

  • Navigate to Record GPS Track.
  • Ensure location permissions are granted. The app can use internal device GPS or an external USB OTG / Bluetooth GPS receiver (configured in Settings).
  • Tap Start to begin logging GPS track points along the railway route. Live position, speed, and signal accuracy are displayed on the map.
  • Tap Stop when finished. The app saves the GPS track and automatically opens the review screen for editing.

3. Reviewing & Editing GPS Track Mileposts

  • Navigate to Milepost GPS Tracks to view recorded tracks.
  • Tap a track to open Review GPS Track.

In this step, you annotate a recorded GPS track to add Milepost numbers. You can also add points of interest on the track -- typically stations or noteworthy places that can later be used to trigger docent annoucements.

Each track has a Label Direction toward Start and a Label Direction toward End. These actually are the labels used to express the travel direction toward the start or the end of the GPS track, respectively.
As most railroads follow a roughly cardinal direction, the recorded GPS path is analyzed the first time and theLabel Direction toward Start and End are initally set according to the relative position of the Start and End points as Southbound/Northbound or Westbound/Eastbound.

  • Tap the track title or top header to set the track label, the start direction label, the end direction label, and the initial/ending milepost values.
  • Tap any line in the GPS track to display its location on the map (visible only in landscape mode).
  • The "MP" number is the milepost number associated with a given GPS point.
  • The "MP" number is displayed in bold when it has been set by the user.
  • The "MP" number is displayed in italics when it is otherwise automatically estimated.
  • Tap on the MP number (bold or italic) to edit the milepost:
    • Set or change the MP number.
    • Enter a Point of Interest label.
    • Ignore a GPS point -- this flags the location point as inaccurate and excludes it from milepost calculations.

4. Programming a Docent Track

A Docent Track combines a GPS Track with Audio Triggers to indicate to the software which audio segment to play when the train reaches specific milepost values. The triggers are based on the milepost number as well as the direction of the train.

To create a new Docent Track:
  • Open the Milepost GPS Tracks from the navigation menu, and select the GPS Track to use.
  • From the Review GPS Track screen, select Create New Docent Track from the 3-dot action menu.
To edit an existing Docent Track, open the Docent Tracks screen from the navigation menu then select the track to edit. This opens the Docent Triggers screen to add or edit docent audio triggers.
  • In the Docent Triggers screen, tap the track title to customize the Docent Track label
  • Tap the floating + button to add play a new audio trigger:
    • Audio File: Select a registered audio segment to associate with this trigger.
    • Milepost Range: Define the start (MP Min) and end (MP Max) mileposts for the trigger ranger.
    • Travel Direction: Choose whether the trigger activates when traveling Towards Higher MP, Towards Lower MP, or in Both directions.
    • Cold Start: Choose whether the trigger can activate if playback starts mid-route within the trigger range.
  • Once an audio trigger is added, the software estimates the playback duration and track coverage overlaid based on the average train speed during the GPS track recording.
Finally, in the Docent Triggers screen, tap the 3-dot action menu and select Playback Docent Track to play back this track.

5. Playback of a Docent Track

In this first iteration of the software, only one Docent Track can be active and enabled to be played at a given time.

To select the currently active Docent Track:
  • Open the Docent Tracks screen from the navigation menu then select the desired Docent Track.
  • In the Docent Triggers screen, tap the 3-dot action menu and select Playback Docent Track to play back this track.
Once a Docent Track has been activated:
  • Navigate to Playback Docent Track.
  • Tap Start to begin live docent operation during a train journey.
  • The app tracks the train's position in real-time, calculates the current milepost and direction of travel, and automatically plays scheduled audio segments as the train enters each trigger range.
  • At the bottom of the screen is a linear representation of the track with all the Points of Interests added in the GPS Track. An icon of a train is shown in real time at the estimated milepost position. The direction of the train icon denotes the detected direction of travel.
  • When the device is in landscape mode, a map also displays the GPS track as well as the current position of the train.
  • The list of all Docent Audio Triggers is shown in the middle of the screen. The currently playing audio segment is highlighted in the list. A control button on the side allows to Force Play, Pause, or Unpause the announcement as needed.

6. Simulation, Testing, & Settings

The Test Sensors screen allows you to inspect live GPS sensor data such as position and accuracy without recording.

The Settings screen offers the following options:
  • Toggle between Imperial (miles, mph) and Metric (km, m/s) units.
  • Configure external USB GPS Receiver: the Android device must support USB OTG. The USB VID:PID of the device to use must be entered in the filter string.
  • Enable simulation: This simulates the GPS position to use in the Playback Docent Track screen. In that case, the GPS position follows the GPS Track recorded instead of the actual device's physical location. This is useful for testing a new Docent Track to ensure that the audio timings are adequate.
